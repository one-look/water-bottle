Developer Setup: Lightweight CPU Installation
============================================

Follow these steps to set up the environment.

1. Clone the Project

    # Clone the repository
    -> git clone https://github.com/one-look/water-bottle.git
    -> cd water-bottle

2. Create and Activate Virtual Environment
------------------------------------------

    It is best practice to keep dependencies isolated:

    # Create the venv (adjust path as needed)
    -> python3 -m venv venv

    # Activate it
    -> source venv/bin/activate

3. Install CPU-Only PyTorch
--------------------------

    To avoid downloading 5GB+ of GPU/CUDA drivers, install the CPU version of Torch first.
    
    -> pip install torch --index-url https://download.pytorch.org/whl/cpu

4. Install Dependencies
----------------------

    Install all required packages from requirements.txt:

    -> pip install -r requirements.txt

5. Set Up Environment Variables
------------------------------

    Copy the example environment file and configure your credentials:

    -> cp .env.example .env
    # Edit .env with your actual API keys and configuration

    Required environment variables:
    - GEMINI_API_KEY: Your Google Gemini API key
    - TELEGRAM_BOT_TOKEN: Your Telegram bot token
    - PINECONE_API_KEY: Your Pinecone API key
    - CONFIG: Path to config file (default: config.yaml)

7. Run the Application
---------------------

    Start the FastAPI server:

    -> uvicorn api.application:app --reload

    The server will be available at http://localhost:8000

8. Test the Setup
-----------------

    Test Pinecone integration:

    -> python3 -m examples.pinecone

    Test Telegram bot by sending a message to your configured bot.

Why we do this:
===============

    Environment variables: Keeps sensitive credentials out of code and enables cloud deployment.

Cloud Deployment
================

For cloud deployment (Railway, AWS, Google Cloud):

1. Set environment variables in your cloud platform
2. Use the provided Dockerfile
3. Set TELEGRAM_WEBHOOK_URL to your cloud domain

The application is fully containerized and cloud-ready!
